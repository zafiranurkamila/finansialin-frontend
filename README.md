# Finansialin Frontend

Frontend Next.js untuk Finansialin dengan alur:

1. Tampilan awal dengan teks ketikan `Selamat datang di Finansialin`
2. Tombol `Login` dan `Register`
3. Form login/register
4. Layar OTP code 6 digit

## Jalankan

```bash
npm install
npm run dev
```

## Catatan

- Folder ini masih berupa scaffold frontend.
- Kode login/register/OTP saat ini masih UI flow dulu.
- Nanti bisa disambungkan ke backend Laravel Finansialin dari repo utama.
